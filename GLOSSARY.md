# BaziFlowAgent

Chinese Daily Almanac and Blindman Bazi fortune-telling agent.

## Language

**Destiny Profile**:
The core astrological identity and birth chart facts of a user, comprising True Solar Time four pillars, visualized chart diagram, and foundational destiny analysis.
_Avoid_: User Bazi, Horoscope, User State

**Destiny Analysis**:
The detailed Blindman Bazi (盲派命理) Chain-of-Thought reading derived from a Destiny Profile.
_Avoid_: Fortune Reading, Prediction, Interpretation

**Consultation Turn**:
An interactive question-and-answer exchange between a user and the AI assistant, contextualized by the user's immutable Destiny Profile and bounded conversation history.
_Avoid_: Chat Message, Prompt, User Query

**Daily Fortune**:
A daily astrological reading correlating a user's Destiny Profile with traditional Chinese Almanac (Huangli) data for a target calendar day.
_Avoid_: Daily Horoscope, Date Reading

**Date Selection**:
A specialized astrological consultation evaluating a candidate date window against a user's Destiny Profile and traditional Almanac data to identify auspicious timing for a specified activity.
_Avoid_: Pick Date, Auspicious Day Finder
