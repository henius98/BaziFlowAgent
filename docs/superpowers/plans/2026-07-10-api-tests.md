# API Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create comprehensive integration tests for all `src/api/handlers.rs` endpoints using an in-memory SQLite database and Mockito for external LLM/MingDecode calls.

**Architecture:** Create a central `tests/api_tests.rs` file containing a `setup_test_app()` function that initializes `AppState`, mocks, and returns the Axum router. Then, create distinct tests for each API route using `tower::ServiceExt::oneshot`. TDD principles apply per the relaxed TDD agreement: write test -> verify failure -> fix test/mocks to pass.

**Tech Stack:** Rust, axum, sqlx, mockito, tokio, tower.

## Global Constraints

- Use in-memory SQLite (`sqlite::memory:`)
- Write tests sequentially and independently for each endpoint.
- Since handlers exist, the "Watch It Fail" step will often mean asserting an incorrect expected value first or temporarily misconfiguring the mock, running it to see the failure, and then correcting it to pass.

```rust
use axum::{
    body::Body,
    http::{Request, StatusCode, header},
};
use baziflow_agent::api::mod::api_router;
use baziflow_agent::config::AppConfig;
use baziflow_agent::models::AppState;
use baziflow_agent::repos;
use mockito::Server;
use sqlx::SqlitePool;
use std::sync::Arc;
use tower::ServiceExt; // for `oneshot` and `ready`

async fn setup_test_app() -> (axum::Router, Server, Arc<AppState>) {
    let pool = SqlitePool::connect("sqlite::memory:").await.unwrap();
    sqlx::migrate!().run(&pool).await.unwrap();

    // Insert dummy user and API key
    let user_id = repos::create_user(&pool, 123456789, "test_user").await.unwrap();
    repos::generate_api_key(&pool, user_id).await.unwrap();
    let api_key = repos::get_user_api_key(&pool, user_id).await.unwrap().unwrap();

    let mut server = Server::new_async().await;
    let mock_url = server.url();

    let config = AppConfig {
        telegram_bot_token: "".into(),
        llm_client_config: baziflow_agent::services::llm::LlmClientConfig {
            api_key: "test".into(),
            api_base: mock_url.clone(),
            timeout_seconds: 30,
            http_client: None,
        },
        llm_model_name: "gpt-4o".into(),
        database_url: "sqlite::memory:".into(),
        user_contexts_expiration_minutes: 60,
        context_cleanup_cron: "".into(),
        log_cleanup_cron: "".into(),
        app_timezone: chrono_tz::Tz::UTC,
        log_retention_days: 7,
        max_context_messages: 10,
        base_url: "http://localhost".into(),
        log_level: "info".into(),
        r2_account_id: None,
        r2_access_key_id: None,
        r2_secret_access_key: None,
        r2_bucket_name: None,
    };

    let state = Arc::new(AppState::new(reqwest::Client::new(), pool.clone(), Arc::new(config)));
    
    // We use a global state pattern in models for some extractors.
    baziflow_agent::models::init_state(state.clone());

    let app = api_router();
    (app, server, state)
}
```
